# ADR-ONB-008: Requirement Candidates Before Delivery Scope

## Status
Accepted

## Context
Discovery outputs should evolve into structured requirement candidates before formal project scoping or provisioning.

## Decision
Capture pre-scope requirements in `requirement_candidates`, linked to source session and (optionally) source response.

## Consequences
- Requirements can be iterated before commitment.
- Candidate lineage to discovery responses is preserved.
